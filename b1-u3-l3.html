Objective: Express hypothetical and imaginary situations using the Second Conditional.

2. Grammar: The Second Conditional

We use the Second Conditional to talk about imaginary, hypothetical, or impossible situations in the present or future. It has two parts:

The Imaginary Condition
IF + Past Simple

Even though it uses the Past Simple, it talks about the present.

"If I had more time..." (Si yo tuviera más tiempo...)
"If she built an app..."
The Imaginary Result
WOULD (or WOULDN'T) + Base Verb

This is what would happen if the condition were true.

"...I would code a game." (...yo programaría un juego).
"...it wouldn't have bugs."
🚨 THE "IF I WERE" RULE

In the Second Conditional, when we use the verb To Be for the pronoun I, He, She, It, we don't use "was". We use "WERE" for everyone to show it is an imaginary situation.

❌ If I was a programmer, I would launch an app.
✅ If I WERE a programmer, I would launch an app.
