2. Grammar: The Third Conditional

We use the Third Conditional to talk about the past. Specifically, we use it to imagine a different past that didn't happen (regrets, mistakes, or alternate realities). It requires a very long formula!

The Complete Formula
IF + Past Perfect (had + V3), Subject + WOULD HAVE + V3

You need "had" in the condition, and "would have" in the result. Both verbs must be in the 3rd column (Past Participle).

"If I had studied, I would have passed the test." (Si yo hubiera estudiado, habría pasado).
"If she had saved the file, it wouldn't have crashed." (Si ella hubiera guardado el archivo, no habría colapsado).
🚨 THE DOUBLE "WOULD" TRAP

Just like the First Conditional (no "will" with "If"), in the Third Conditional, you NEVER put "would have" next to "If".

❌ If I would have known, I would have helped you.
✅ If I HAD KNOWN, I would have helped you.

Reading Context: HTML at Colegio Fielding

"In my classes at Colegio Fielding, I also like to teach my students some practical digital skills. Yesterday, I taught Leonardo Barron and Cristopher Ramos some coding basics. We were building a simple webpage using HTML."

"Leonardo made a mistake while typing. He opened an <h1> heading tag, but he forgot to close the tag. Because of this, all the text on the website became massive! He was very frustrated. I smiled and told him: 'If you had closed the tag properly, the text wouldn't have looked like a giant monster.'"

"Cristopher laughed at Leonardo, but then he accidentally deleted his own file! He had to start from zero. If Cristopher had backed up his work, he would have saved a lot of time. In the end, we had to debug the code together. Learning HTML is exactly like learning English: you learn from your past mistakes!"
