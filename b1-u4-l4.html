Coding Basics: App Updates

Objective: Report recent progress and updates using the Present Perfect Passive.

1. Vocabulary: Software Development

Learn these regular verbs to talk about creating and launching digital projects.

🚀 Develop Desarrollar V3: Developed
🎨 Design Diseñar V3: Designed
🔧 Fix Arreglar / Reparar V3: Fixed
⬇️ Install Instalar V3: Installed

2. Grammar: Present Perfect Passive

When you want to announce that a project is recently finished or updated, but you don't need to say who did it, you use the Present Perfect Passive.

Singular (Has been)
One Object + HAS BEEN + V3
"The app has been developed." (La app ha sido desarrollada).
"The bug has been fixed." (El error ha sido arreglado).
Plural (Have been)
Many Objects + HAVE BEEN + V3
"The files have been installed."
"The designs have been updated."
🚨 THE FORGOTTEN "BEEN" TRAP

Because the Active Present Perfect uses "have/has + V3" (I have finished), students often forget to add the word BEEN in the Passive Voice. Without "been", the sentence means the object did the action itself!

❌ The app has launched. (La app "ha lanzado" a alguien más).
✅ The app has BEEN launched. (La app ha sido lanzada).

Reading Context: The App Launch

"As a teacher and graphic designer, I have been working on a special project for my students in Sucre. Today, I have great news: my new application, 'Teacher Ivan - Health and Fitness', has been developed!"

"A lot of work was required. The user interfaces have been designed to be friendly and fast. The exercise libraries for CrossFit have been added to the database. Last week there were some system errors, but thanks to my research, all the bugs have been fixed."

"Now, the app has been installed by many users. The latest training routines have been updated, and new features have been requested by Lau. The digital HUB is finally complete!"
